# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Do not open a public GitHub issue.**

Instead, email: **security@example.com**

We will respond within 48 hours and work with you to understand and resolve the issue.

## Scope

This is a static landing page with no backend, database, or authentication. The attack surface is limited to:

- Cross-site scripting (XSS) via user-generated content (currently none)
- Dependency vulnerabilities in npm packages
- Content injection via external image URLs
